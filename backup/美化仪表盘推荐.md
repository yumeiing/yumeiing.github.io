每次打开终端，只有黑乎乎的命令行闪烁着。
如果你也想要个性化的终端仪表盘，那么这款`fastfetch`很适合你。
## 介绍
这是一款轻量级**多平台**终端仪表盘，可自定义展示内容。
![show_fastfetch](./show_fastfetch.png)
## 安装
详细内容请看[fastfetch的GitHub发布页](https://github.com/fastfetch-cli/fastfetch)
### Linux
你可能需要`sudo`,`doas`或者`sup`运行这些命令。

Debian / Ubuntu (Debian 13 或更高版本; Ubuntu 25.04 或更高版本)
```shell
apt install fastfetch 
```
Arch Linux
```shell
pacman -S fastfetch
```
Fedora
```shell
dnf install fastfetch
```
Gentoo
```shell
emerge --ask app-misc/fastfetch
```
NixOS
```shell
nix-shell -p fastfetch
```
### macOS
Homebrew
```shell
brew install fastfetch
```
MacPorts
```shell
sudo port install fastfetch
```
### Windows
scoop
```shell
scoop install fastfetch
```
Chocolatey
```shell
choco install fastfetch
```
winget
```shell
winget install fastfetch
```
MSYS2 MinGW
```shell
pacman -S mingw-w64-<subsystem>-<arch>-fastfetch
```
### 其他
见[fastfetch的GitHub发布页](https://github.com/fastfetch-cli/fastfetch)
## 配置
详细内容请看[fastfetch配置介绍](https://github.com/fastfetch-cli/fastfetch/wiki/Configuration)
可通过以下之一的命令生成配置文件。Linux默认路径为`~/.config/fastfetch/config.jsonc`。
```shell
fastfetch --gen-config # 生成最小配置文件
fastfetch --gen-config-full # 生成完整配置文件
```
### 基本结构
```json
{
    "$schema": "https://github.com/fastfetch-cli/fastfetch/raw/dev/doc/json_schema.json", // Optional: Provides IDE intelligence
    "logo": { /* Logo configuration */ },
    "display": { /* Display settings */ },
    "modules": [ /* Modules to display */ ]
}
```
### 示例
可通过更改配置文件自定义显示内容
```json
{
  "$schema": "https://github.com/fastfetch-cli/fastfetch/raw/dev/doc/json_schema.json",
  "logo": {
      "type": "auto",        // Logo type: auto, builtin, small, file, etc.
      "source": "apple",      // Built-in logo name or file path
      "width": 65,           // Width in characters
      "height": 35,          // Height in characters
      "padding": {
          "top": 0,          // Top padding
          "left": 0,         // Left padding
          "right": 2         // Right padding
      },
      "color": {             // Override logo colors
          "1": "blue",
          "2": "green"
      }
  },
  "modules": [
    "title",
    "separator",
    "os",
    "host",
    "uptime",
    "packages",
    "shell",
    "de",
    "wm",
    "wmtheme",
    "theme",
    "icons",
    "font",
    "terminal",
    "cpu",
    "gpu",
    "swap",
    "disk",
    "battery",
    "poweradapter",
    "locale",
    "break",
    "colors"
  ]
}
```
在命令行输入`fastfetch`即可运行。
